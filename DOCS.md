# Карта документов

Один вход во все документы проекта. Файлов много, потому что у них разные
читатели и разный срок годности; путаница между ними уже дважды стоила
работы — агент действовал по дорожной карте продукта, приняв её за план
работ, и делал то, чего никто не просил.

Правило: **если непонятно, куда писать — пишите сюда и говорите, куда
положить.** Второй документ с тем же назначением хуже, чем длинный первый.

## Куда что писать

| появилось | куда |
|---|---|
| новое измерение | `docs/RESULTS.md` — с оговоркой «чего НЕ доказывает» |
| решение об архитектуре | `MULTI_AGENT_SYNC.md` |
| задача для AGY | `AGY_TASKS.md` |
| изменение сроков или приоритетов | `PLAN.md` |
| новая команда для запуска | `README.md` |
| ответ на вопрос жюри | `docs/DEFENCE.md` |
| идея на будущее | `docs/PRODUCT_ROADMAP.md`, и там она называется идеей |
